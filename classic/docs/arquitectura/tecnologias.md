# Stack Tecnológico

## Frontend

### Core
- **React 18+**: Library UI
- **React Router DOM**: Enrutamiento SPA
- **Axios**: Cliente HTTP

### Estilos
- **CSS3**: Estilos personalizados
- **CSS Modules** / **Styled Components**: Estilos encapsulados
- **Responsive Design**: Media queries y flexbox/grid

### Herramientas
- **Vite** / **Create React App**: Build tool
- **ESLint**: Linting
- **Prettier**: Code formatting

## Backend

### Framework
- **Spring Boot 3.x**: Framework principal
- **Spring Web**: REST API
- **Spring Data JPA**: ORM
- **Spring Security**: Autenticación y autorización

### Base de Datos
- **PostgreSQL**: Base de datos relacional
- **Hibernate**: ORM implementation
- **Flyway** / **Liquibase**: Migraciones (opcional)

### Seguridad
- **JWT (JSON Web Tokens)**: Autenticación stateless
- **BCrypt**: Hash de passwords
- **OAuth2 Client**: Google authentication

### Integraciones
- **MercadoPago SDK**: Procesamiento de pagos
- **Google OAuth2**: Autenticación social

### Herramientas
- **Maven**: Gestión de dependencias
- **Lombok**: Reducción de boilerplate
- **MapStruct**: Mapeo de DTOs (opcional)

## DevOps

### Contenedorización
- **Docker**: Containerización de aplicaciones
- **Docker Compose**: Orquestación multi-container

### Despliegue
- **VPS**: Servidor privado virtual
- **Nginx**: Reverse proxy (opcional)
- **GitHub Actions**: CI/CD (opcional)

## Versiones Recomendadas

```yaml
Frontend:
  Node: 20.x LTS
  React: 18.2+
  React Router: 6.x

Backend:
  Java: 21 LTS
  Spring Boot: 3.2.x
  PostgreSQL: 15+

DevOps:
  Docker: 24.x
  Docker Compose: 2.x
```
